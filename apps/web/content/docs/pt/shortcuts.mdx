---
title: Atalhos
description: Tudo tem atalho, nada depende de atalho.
---

| Atalho | Ação |
|---|---|
| <Kbd>1</Kbd> a <Kbd>8</Kbd> | Abrir módulo no painel em foco |
| <Kbd>[</Kbd> <Kbd>]</Kbd> | Painel anterior / seguinte |
| <Kbd>Ctrl+K</Kbd> ou <Kbd>/</Kbd> | Paleta de comandos ("ler holding 40001") |
| <Kbd>Ctrl+Enter</Kbd> | Conectar ou desconectar |
| <Kbd>R</Kbd> | Ler agora |
| <Kbd>P</Kbd> | Iniciar ou pausar leitura cíclica |
| <Kbd>A</Kbd> | Adicionar tag |
| <Kbd>W</Kbd> | Escrever na tag selecionada (abre confirmação) |
| <Kbd>L</Kbd> | Iniciar ou parar o data logger |
| <Kbd>M</Kbd> | Adicionar marcador de evento |
| <Kbd>G</Kbd> | Gerar o relatório PDF |
| <Kbd>?</Kbd> | Ajuda de atalhos |

Atalhos de uma letra só funcionam fora de campos de texto. Alt+setas, Ctrl+P e Espaço ficam com o comportamento do navegador. Na confirmação de escrita, <Kbd>Enter</Kbd> confirma e <Kbd>Esc</Kbd> cancela.
