---
title: Tastenkürzel
description: Alles hat ein Kürzel, nichts hängt von einem ab.
---

| Kürzel | Aktion |
|---|---|
| <Kbd>1</Kbd> bis <Kbd>8</Kbd> | Modul im fokussierten Bereich öffnen |
| <Kbd>[</Kbd> <Kbd>]</Kbd> | Vorheriger / nächster Bereich |
| <Kbd>Ctrl+K</Kbd> oder <Kbd>/</Kbd> | Befehlspalette („lesen holding 40001“) |
| <Kbd>Ctrl+Enter</Kbd> | Verbinden oder trennen |
| <Kbd>R</Kbd> | Jetzt lesen |
| <Kbd>P</Kbd> | Zyklisches Lesen starten oder pausieren |
| <Kbd>A</Kbd> | Tag hinzufügen |
| <Kbd>W</Kbd> | In den ausgewählten Tag schreiben (öffnet die Bestätigung) |
| <Kbd>L</Kbd> | Datenlogger starten oder stoppen |
| <Kbd>M</Kbd> | Ereignismarkierung hinzufügen |
| <Kbd>G</Kbd> | PDF-Bericht erzeugen |
| <Kbd>?</Kbd> | Hilfe zu Kürzeln |

Einbuchstabige Kürzel funktionieren nur außerhalb von Textfeldern. Alt+Pfeiltasten, Ctrl+P und Leertaste behalten ihr Browserverhalten. In der Schreibbestätigung bestätigt <Kbd>Enter</Kbd> und <Kbd>Esc</Kbd> bricht ab.
