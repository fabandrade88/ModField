ModField liest, schreibt, scannt, simuliert und zeichnet Modbus-RTU- und -TCP-Geräte im Browser auf. Ohne Agent arbeitet es mit einem USB-RS485-Wandler über Web Serial. Mit dem lokalen Agenten (ohne Administratorrechte installiert) kommen Modbus TCP, Portnamen wie COM3 und Aufzeichnung bei geschlossenem Tab hinzu.

## Wo anfangen

- [Das erste Register über USB-RS485 lesen](/de/docs/quick-start-usb) — 5 Minuten, keine Installation.
- [Das erste Register über Modbus TCP lesen](/de/docs/quick-start-tcp) — braucht den Agenten.
- [Den Agenten ohne Administratorrechte installieren](/de/docs/install-agent).
