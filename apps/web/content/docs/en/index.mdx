ModField reads, writes, scans, simulates and logs Modbus RTU and TCP devices from the browser. Without the agent it works with a USB-RS485 converter through Web Serial. With the local agent (installed without administrator rights) it adds Modbus TCP, port names such as COM3 and logging with the tab closed.

## Where to start

- [Read the first register over USB-RS485](/en/docs/quick-start-usb) — 5 minutes, nothing to install.
- [Read the first register over Modbus TCP](/en/docs/quick-start-tcp) — needs the agent.
- [Install the agent without administrator rights](/en/docs/install-agent).

- [Find an unknown slave](/en/docs/guides/find-slave)
