---
title: Shortcuts
description: Everything has a shortcut; nothing depends on one.
---

| Shortcut | Action |
|---|---|
| <Kbd>1</Kbd> to <Kbd>8</Kbd> | Open module in the focused pane |
| <Kbd>[</Kbd> <Kbd>]</Kbd> | Previous / next pane |
| <Kbd>Ctrl+K</Kbd> or <Kbd>/</Kbd> | Command palette ("read holding 40001") |
| <Kbd>Ctrl+Enter</Kbd> | Connect or disconnect |
| <Kbd>R</Kbd> | Read now |
| <Kbd>P</Kbd> | Start or pause cyclic reading |
| <Kbd>A</Kbd> | Add tag |
| <Kbd>W</Kbd> | Write to the selected tag (opens the confirmation) |
| <Kbd>L</Kbd> | Start or stop the data logger |
| <Kbd>M</Kbd> | Add an event marker |
| <Kbd>G</Kbd> | Generate the PDF report |
| <Kbd>?</Kbd> | Shortcut help |

Single-letter shortcuts only work outside text fields. Alt+arrows, Ctrl+P and Space keep their browser behavior. In the write confirmation, <Kbd>Enter</Kbd> confirms and <Kbd>Esc</Kbd> cancels.
